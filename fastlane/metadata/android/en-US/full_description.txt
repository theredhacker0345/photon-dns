<p>Pocket Relay turns an idle spare Android phone into a private, owner-controlled AI agent host. It runs a reviewed Hermes Agent worker in embedded CPython as a native Android foreground service. No external terminal application is required or shown.</p>

<p><b>Key features</b></p>
<ul>
<li><b>Private embedded runtime:</b> a constrained, owner-locked Hermes Agent worker runs in embedded CPython.</li>
<li><b>Telegram remote control:</b> long polling is restricted to an authorized owner chat ID.</li>
<li><b>24/7 host service:</b> a persistent Android service is designed for a charger-connected spare phone.</li>
<li><b>Live host telemetry:</b> CPU load, RAM, storage readiness, and charging state come from the native runtime.</li>
<li><b>Local notifications, not push tracking:</b> backup reminders and host safety alerts are Android-local; Pocket Relay uses no Firebase, Google Play Services, analytics, crash reporting, or push token.</li>
<li><b>FOSS and transparent:</b> Pocket Relay is GPL-3.0-only with source-side dependency, provenance, and license evidence.</li>
</ul>

<p>The owner configures model-provider and Telegram connections. They require internet access, so Pocket Relay does not claim to be offline-first.</p>
