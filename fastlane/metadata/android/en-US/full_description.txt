Pocket Relay is a FOSS (Free and Open Source Software) Android application that transforms an idle spare phone into a 24/7 self-hosted AI agent host. Designed around a private embedded CPython and Hermes Agent runtime, Pocket Relay runs entirely as a native Android foreground service without requiring or displaying any external terminal user interface like Termux.

Key Features:
- **Private Embedded Runtime**: Bundles a constrained, owner-locked Hermes Agent worker executing within an embedded CPython environment.
- **Telegram Remote Control**: Securely communicates via Telegram long-polling restricted strictly to an authorized owner chat ID, keeping your agent private and protected.
- **24/7 Foreground Service**: Operates persistently in the background with `START_STICKY`, designed for old phones connected to a charger.
- **Real-Time Telemetry**: Monitors device CPU load, RAM usage, storage readiness, and battery charging state directly from the native Android runtime.
- **Local Notifications, Not Push Tracking**: Backup reminders, safety alerts, and notification tests are delivered by Android locally. Pocket Relay does not use Firebase, Google Play Services, analytics, crash reporting, or a push token.
- **FOSS and Transparent**: Pocket Relay is GPL-3.0-only. The release tree includes dependency and license evidence, an F-Droid recipe, and a documented unsigned-release policy.
- **Polished Mobile Control Plane**: Built with Expo and React Native, featuring a clean portrait control panel for managing agent status, automations, and secure settings.

Model-provider and Telegram connections are configured by the owner and require the internet; Pocket Relay does not pretend to be an offline-first agent. Turn an old phone into your personal, owner-controlled AI relay today.
