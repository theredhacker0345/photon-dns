# Creator Attribution Source

Pocket Relay’s concise creator attribution is based on the public portfolio of Ubaid ur Rehman: <https://ubaid-ur-rehmanportfolio.vercel.app/>.

The portfolio identifies Ubaid ur Rehman as a self-taught developer, security researcher, and FOSS developer. The product interface deliberately uses only this short, relevant attribution: **“Created by Ubaid ur Rehman — a self-taught FOSS developer and security researcher.”** It excludes age, location, certifications, and unrelated portfolio details.

The owner supplied the Hire contact details directly in the project request. They are not derived from the portfolio.
